## Final Report Notes

- The final dashboard deliverable is the static storytelling site at `report/index.html`.
- Open `report/index.html` in a browser to view the final dashboard/report.
- Supporting styling and interaction live in:
  - `report/site.css`
  - `report/site.js`
- The report embeds cleaned figures and interactive outputs generated into `data/cleaned/`.
- Final headline metrics shown in the dashboard:
  - `1,199` basins analyzed
  - `292` high-risk basins in 2030
  - `297` high-risk basins in 2050
  - `271` persistent hotspots in both years
- Hotspot definition used across the final report:
  - `bau30_ws_x_r >= 0.4` for the baseline hotspot threshold
  - 2050 persistence/emergence summaries compare `bau30_ws_x_r` and `bau50_ws_x_r`
